# 🎬 CinemaClub — פרויקט הכיתה

אתר סרטים ב־React. עובדים עליו כל הסמסטר: בכל שיעור הוא גדל עוד קצת.

**איך בנוי המאגר**

```
movie-site/
├── lesson-04/      ← הפרויקט בתחילת שיעור 4
├── lesson-05/      ← יתווסף בשיעור הבא
└── ...
```

כל תיקייה היא פרויקט React שלם. בתחילת כל שיעור מתווספת תיקייה חדשה, ואת התיקיות הקודמות לא משנים.

**הפעלה**

```
cd lesson-04
npm install
npm run dev
```

ואז פותחים בדפדפן את הכתובת שמופיעה בטרמינל, בדרך כלל `http://localhost:5173`.

**איך מקבלים תיקייה חדשה**

1. ב־GitHub, במאגר **שלכם** (ה־Fork), לוחצים **Sync fork** ואחר כך **Update branch**.
2. בטרמינל, בתיקייה `movie-site`:

```
git pull
```
